# はてなブログ下書きストック自動生成ジェネレーター (Yahoo!ショッピングリサーチ版)

Yahoo!ショッピングAPIを活用して売れ筋・注目商品を自動リサーチし、高CTRな洗練されたHTMLレビュー記事を下書き（Draft）として自動保存するシステムです。

## 特徴
1. **下書き（Draft）限定投稿**:
   記事は公開されず、はてなブログの「下書き」にのみ保存されるため、安心してストックできます。
2. **公式アフィリエイトリンクのワンクリック差し替え**:
   記事内のCTAボタンにはYahoo!ショッピングの正規商品URLが仮セットされています。はてなブログの管理画面から、LINEヤフー公式の共有リンク（`yahoo.jp/...` など）に差し替えて公開するだけで完了します。
3. **洗練されたHTMLデザイン**:
   - 冒頭3行のフック文
   - 黄金比のグラデーション高CTRボタン
   - 複数アングル画像ギャラリー
   - 信頼感を高めるスペック＆素材解説
   - ステルスマーケティング規制に対応したPR表記
